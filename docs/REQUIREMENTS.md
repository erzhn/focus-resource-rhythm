# Зафиксированные требования

Источник — авторское ТЗ методики «Фокус — Ресурс — Ритм». Ниже — краткая фиксация; статус реализации
см. в [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md).

## Методика
- **Фокус**: зоны «Сейчас / Следом / Позже / Отказ»; не более 3 активных крупных результатов; отказ
  сохраняется в истории, не удаляется бесследно.
- **Ресурс**: перед запуском — проверка зачем/результат/время/деньги/силы/зависимости/реалистичность
  срока; при нехватке — подготовительное действие, уменьшение, разделение, перенос.
- **Ритм**: горизонты год / 90 дней / месяц / неделя / день; день = 1 главное + до 2 доп +
  обязательные повторяющиеся; цепочка «Сфера → Цель → Проект → Этап → Задача → Ближайшее действие».
- **Правила**: у активного плана есть ближайшее физическое действие; резерв 20–30% (по умолчанию 25%);
  срочность не отменяет важность; перенос — с обязательной причиной; система рекомендует, решает
  пользователь; невыполненная задача не переносится автоматически.

## Регион
Часовой пояс `Asia/Bishkek`; время 24ч; дата `дд.мм.гггг`; валюта `KGS`; неделя с понедельника;
timestamps — UTC.

## Функциональность
- Быстрое создание задачи + вопрос о формулировке + пошаговый помощник.
- Объяснимый приоритет 0–100 с факторами и ручным override.
- План/факт и лимиты времени, сил, денег; предупреждения (можно подтвердить сознательно).
- Утренний план (черновик→подтверждение) и вечерний итог; еженедельная сверка.
- Повторяющиеся задачи всех типов + изменение отдельного экземпляра.
- Календарь: день/неделя/месяц/год, порядок и временные блоки, drag-and-drop, фиксированные/гибкие
  события, варианты при перегрузке.
- Двусторонняя синхронизация Google/Outlook с выбором календарей, календарём по умолчанию,
  подтверждением внешних изменений и историей версий.
- Внутренние уведомления, ведущие к действию. Дашборд и статистика на реальных данных.

## Нефункциональные
- Данные изолированы по `user_id`, RLS на всех пользовательских таблицах.
- Деньги — `numeric`, не float. Секреты — вне репозитория. Токены — зашифрованы, только сервер.
- Адаптивность (375/768/1440), доступность, отсутствие горизонтального скролла на мобильном.
- Проходят lint, typecheck, tests, production build.

## Вне первой версии
Команды, роли, совместная работа, оплата, публичный сайт, Telegram/email/SMS-push, нативные
приложения, тяжёлый обязательный AI, микросервисы ради архитектуры.
