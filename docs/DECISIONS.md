# Принятые решения (ADR-лайт)

## 1. Каталог проекта
Приложение создано в `D:\PET-projects\planning` (пустой каталог, добавленный в рабочее пространство),
а не в `panorama_mobile` (это отдельное Flutter-приложение по недвижимости). Смешивать их нельзя.

## 2. Демо-режим вместо in-memory-подмены реального продукта
В среде разработки нет Docker и нет ключей Supabase, поэтому локально нельзя поднять PostgreSQL.
Решение:
- Написан **реальный** слой данных: SQL-миграции всех таблиц, RLS, триггеры. Это основной путь.
- Для локального просмотра без ключей включается **демо-режим** (данные в памяти), который **явно
  обозначен** в интерфейсе (баннер, бейдж, экран настроек). Это соответствует разрешению ТЗ §1.6 на
  демонстрационный режим без OAuth-ключей и не выдаётся за постоянное хранилище.
- Переключение автоматическое: как только заданы `NEXT_PUBLIC_SUPABASE_URL` и `..._ANON_KEY`,
  приложение должно работать с реальной БД (интерфейс стора спроектирован под замену провайдера).

## 3. Деньги
В домене расчёты ведутся в **минорных единицах** (тыйын, целые числа) во избежание ошибок float.
В БД денежные поля — `numeric(14,2)`. На границе — конвертация.

## 4. Время и часовой пояс
Метки времени в БД — `timestamptz` (UTC). Часовой пояс пользователя — отдельная настройка
(`Asia/Bishkek` по умолчанию). Форматирование — на границе UI (`src/lib/format.ts`).

## 5. Доменная логика — чистая и тестируемая
Приоритеты, план дня, повторения, конфликты, зоны фокуса вынесены в `src/domain/**` как чистые
функции без зависимостей от React/БД. Веса приоритета — в отдельном конфиге. Покрыто Vitest.

## 6. Помощник формулировки без обязательного LLM
`TaskFormulationService` — интерфейс; реализация по умолчанию `TemplateFormulationService`
детерминированная. AI-адаптер можно добавить позже через ту же абстракцию; отсутствие ключа
не ломает основной сценарий.

## 7. Приоритет: система vs. ручной
Системная рекомендация и ручное значение хранятся **раздельно** (`system_priority`, `manual_priority`).
UI показывает и итог, и исходную рекомендацию.

## 8. UI-стек
Собственные лёгкие компоненты на Tailwind вместо тяжёлой библиотеки — быстрее и без платных лицензий.
Иконки — lucide-react. Графики (позже) — Recharts.

## 9. Календарная синхронизация — схема вперёд кода
Полная схема данных синхронизации заложена сразу (провайдер, аккаунт, внешний календарь, etag/changeKey,
sync-токены, запросы подтверждения, версии), чтобы включение OAuth не требовало миграций-переделок.
